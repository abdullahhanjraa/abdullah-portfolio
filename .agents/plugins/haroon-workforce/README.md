# Haroon AI Workforce Operating System Plugin

The Antigravity-native plugin bundle connecting the Founder's IDE directly to the deterministic **Haroon AI Boss Engine** at `F:\haroon assistant`.

## Features
- **IDE Command:** `/haroon <task>` (or `/boss <task>`)
- **Deterministic Orchestration:** Kahn DAG topological sorting, 4-tier policy gating, Reality Gate machine verification.
- **Embedded MCP Server:** Stdio JSON-RPC 2.0 communication with `F:\haroon assistant\src\mcp\server.js`.
- **Persistent Knowledge:** ACID SQLite storage in `company.db` with facts and user preferences.
